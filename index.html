Principe

Les deux utilisateurs saisissent le même code de salon. Les messages sont chiffrés sur l'appareil avant d'être envoyés : le relais ne voit que du texte illisible.

Salon privé

Un seul utilisateur génère le code, puis le transmet à l'autre par un canal sûr (en main propre, par exemple). Plus le code est long, mieux c'est.
